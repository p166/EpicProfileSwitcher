# Epic Profile Switcher

[English](README.md) | [Русский](README.ru.md)

Приложение для Windows для сохранения и переключения профилей Epic Games Launcher.

## Возможности

- Сохранение текущей сессии Epic под именем профиля.
- Переключение профилей без блокировки интерфейса. Приложение показывает ход операции и сообщает о запуске лаунчера; если запустить лаунчер не удаётся, исходный файл сессии восстанавливается.
- Запуск новой сессии входа в Epic.
- Переименование и удаление сохранённых профилей.
- Отображение версии приложения и кнопка для перехода на GitHub проекта в главном окне.
- Диалоги, центрированные относительно главного окна.
- Шифрование сохранённых копий сессий с помощью Windows DPAPI для текущего пользователя Windows.
- Проверка обновлений в GitHub Releases, отображение прогресса загрузки, проверка SHA-256 и перезапуск с новой версией.

## Требования

- Windows
- Python 3.10 или новее

## Запуск из исходного кода

В корне репозитория создайте и активируйте виртуальное окружение, установите зависимости для разработки и запустите приложение:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python -m epic_profile_switcher
```

Запуск тестов:

```powershell
pytest -q
```

Автоматическая проверка обновлений включена только в собранном EXE для Windows; при запуске из исходного кода она не выполняется.

## Сборка EXE для Windows

Убедитесь, что `python.exe` доступен через `PATH`, затем запустите скрипт в PowerShell:

```powershell
.\build-windows.ps1
# Необязательно: сохранить копию существующего EXE
.\build-windows.ps1 -Backup
```

Скрипт создаёт или проверяет соответствие `.venv-windows` активной версии Python, устанавливает зависимости для сборки, запускает тесты и собирает оконное однофайловое приложение `dist/windows/EpicProfileSwitcher.exe`. На компьютере пользователя Python не требуется. Первый запуск может занять больше времени: файлы, включённые в EXE, распаковываются во временную папку.

## Релизы и автоматические обновления

GitHub Actions запускает сборку релиза после отправки тега `v*`. Также workflow можно запустить вручную, указав тег. Чтобы опубликовать релиз:

1. Установите нужное значение `__version__` в `src/epic_profile_switcher/__init__.py`.
2. Отправьте соответствующий тег, например `v1.4` для версии `1.4`, либо вручную запустите workflow **Windows release** с этим тегом.
3. Workflow соберёт EXE и опубликует в GitHub Release файлы `EpicProfileSwitcher.exe` и `EpicProfileSwitcher.exe.sha256`.

Собранное приложение проверяет последний GitHub Release. Если доступна новая версия, оно предлагает **Update** (обновить), **Later** (позже) или **Skip version** (пропустить версию). Пропущенная версия запоминается в настройках пользователя. После подтверждения приложение показывает прогресс загрузки, сверяет EXE с SHA-256 из релиза, закрывается, заменяет себя и запускается заново. EXE должен находиться в папке, доступной для записи текущему пользователю Windows.

## Хранение и шифрование профилей

Профили хранятся в `%LOCALAPPDATA%\EpicProfileSwitcher\profiles\<profile-id>`. Сохранённая копия сессии находится в `session.ini.dpapi` и защищена с помощью Windows Data Protection API (DPAPI): используются `CryptProtectData` и `CryptUnprotectData` с областью действия по умолчанию для текущего пользователя Windows. Приложение не запрашивает отдельный пароль и не хранит собственный ключ шифрования — ключевыми данными управляет Windows.

Шифруется только сохранённая копия сессии. Сопутствующий файл метаданных `profile.json` не зашифрован и содержит имя профиля, дату создания, идентификаторы секций аккаунта и хеши, используемые для определения активного профиля. Не считайте имена профилей и эти метаданные секретными.

При переключении приложение расшифровывает копию профиля и записывает данные сессии в обычный файл Epic, чтобы лаунчер мог ими воспользоваться. Epic Profile Switcher не шифрует этот активный файл. Во время сохранения и восстановления открытые данные сессии также неизбежно находятся в памяти.

DPAPI защищает сохранённые копии от пользователей и процессов, у которых нет доступа к DPAPI-данным текущего пользователя Windows. Это не защита от вредоносных программ и других приложений, запущенных от имени того же пользователя: они могут попросить Windows расшифровать данные. Обычно сохранённые копии нельзя расшифровать после переноса на другой компьютер или в другую учётную запись Windows. Если DPAPI-данные учётной записи Windows потеряны или недоступны, восстановить копии может быть невозможно.

## Расположение Epic Games Launcher

Приложение ищет лаунчер в стандартных папках установки и в записях Windows об удалении программ. Если Epic установлен в нестандартное место и не зарегистрирован в Windows, нажмите **Browse…** и выберите `EpicGamesLauncher.exe`.
